# 15: 文本导入：匹配题

**What to build:** 「一组共用选项 + 多个子题」的题能从粘贴文本识别成一道匹配题：`共用选项：` 块（A–J）后跟编号子题列表（子题标注单选 / 多选），答案段按子题序号对应；校对页以匹配题一行显示，答案框沿用源文件格式 `1 AB　2 C`。

**Blocked by:** 14 文本导入：答案在末尾、范围写法、判断题

**Spec:** spec.md「用户故事 15」「解析规则（匹配题识别）」

**Status:** resolved

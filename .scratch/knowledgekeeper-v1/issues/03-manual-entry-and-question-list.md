# 03: 录入单选 / 多选 / 判断题，分组页列出题目

**What to build:** 用户用「录入」表单手动录入单选题、多选题或判断题：选题型和分组（默认「错题集」，记住上次选择），填题干、选项、正确答案、解析，保存后题目出现在分组页的列表里，表单清空以便连续录入。分组页按导入顺序列出题目，空分组有明确状态。

**Blocked by:** 01 行走骨架

**Spec:** spec.md「用户故事 19、23、26」「数据模型」「界面设计 · 录入页 / 分组页」

**Status:** resolved

- [x] 顶栏加入「录入」导航项；录入页：标题「录入一道题」、副标、第一行两个 select（题型、放进哪个分组）
- [x] 题型决定表单形态：单选 / 多选是题干 + 选项行（字母、输入框、40px「正确」按钮；单选只能点一个，多选可点多个）+「＋ 再加一个选项」+ 解析；判断题是题干 +「正确 / 错误」二选一 + 解析，没有选项行
- [x] 选项行可删，字母自动重排；数量不设上限
- [x] 校验：题干非空；选择题至少 2 个选项；单选恰好 1 个答案、多选至少 2 个；判断题有答案。不满足时「保存到题库」禁用并提示缺什么
- [x] 保存后留在表单、字段清空、toast「已保存到「组名」」；分组 select 记住上次选择（按设备的 UI 状态，不经过应用核心、不进备份）
- [x] 分组页：面包屑「我的题库 / 组名」、标题、副标「N 道题…」、按导入顺序的题目行（题型标签、题干、「N 对 N 错」右对齐），新录入的排在最后
- [x] 空分组：列表位置「这一组还没有题。」+「录入」按钮（跳到录入页并预选本组）
- [x] 判断题的选项固定为「√ 正确」「× 错误」，答案即 √ 或 ×
- [x] seam 测试：录入单选 / 多选 / 判断题后，题目列表的内容、顺序、题型与答案与录入一致；解析可空
- [x] 录入页右轨「录入」说明

# 13: 粘贴文本导入：解析、校对、写入

**What to build:** 用户把从网页复制的题粘贴进文本框，选好目标分组，点「开始校对」后进入校对页：每道识别出的题一行，题干、选项、答案（可改）、题型标签，缺答案的标红并在顶部警示条里报数；补齐答案后警示条转绿、写入按钮解禁；点「写入 N 道题」后题目进入分组，跳到分组页。本张覆盖题号写法、选项、「答案紧跟题目」格式、解析提取、题型推断（单选 / 多选）、缺答案警示和 0 题报错。

**Blocked by:** 04 分组管理与应用内对话框

**Spec:** spec.md「用户故事 1、2、4–8、11、14」「解析规则」「界面设计 · 导入页」

**Status:** resolved

- [x] 顶栏加入「导入」；导入页第一步：标题「导入题目」、副标、药丸「支持 .pdf .docx .xlsx .xls」「.doc 需先另存为 .docx」、等宽白底可编辑文本框、「放进哪个分组」select（默认按 04 的规则，末项「＋ 新建分组…」）、主按钮「开始校对」；「从「文件」选择」与工具栏提示在 17 加

- [x] 解析：题号 `1.` / `1、` / `(1)` / `01`；选项 `A.` / `A、` / `A．`；逐题写法的答案（`答案：A` 或 `1A 2B`）；题后紧跟的「解析：…」提取为可选字段；题型推断：答案含 2 个以上字母 → 多选题，选项为「正确 / 错误 / √ / ×」或答案为判断符号 → 判断题，否则单选题
- [x] 校对页：顶部警示条 sticky 在顶栏下方，缺答案时橙色「识别到 N 道题，答案 M 个。第 7、9 题缺答案，标红了。」，题号可点并滚到那一行；补齐后转绿「识别到 N 道题，答案 N 个，都齐了。」；右侧唯一的主动作「写入 N 道题」随之解禁
- [x] 每行：两位序号、题型小标签 + 题干、选项行（灰）、右侧答案框（缺答案红框、占位「缺答案」；统一大写、去空格；字母不在选项范围内视为缺答案）、操作行（本张只有「删除」；其余在 16 加）
- [x] 底部「← 重新粘贴」回第一步并保留文本框内容
- [x] 写入成功 toast「已写入 N 道题到「组名」」并跳到该分组页；`commitReview` 写入前校验草稿（题干非空、每题有合法答案），不通过则报错、不写入，绝不静默

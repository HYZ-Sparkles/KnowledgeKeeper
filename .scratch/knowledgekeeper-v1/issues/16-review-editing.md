# 16: 校对页编辑：行内编辑、改题型、拆分、合并

**What to build:** 解析错了不用重新粘贴：在校对页点「编辑题干」或「改题型」，这一行展开成和录入页一样的编辑器改完「完成」；两道题被粘成一道时把光标放在题干里「从此处拆分」，一道题被拆成两半时「与下一题合并」；改题型只允许 单选 ↔ 多选 ↔ 判断。所有编辑即时反映到警示条与写入按钮。

**Blocked by:** 06 题目页：编辑与删除, 15 文本导入：匹配题

**Spec:** spec.md「用户故事 5、8」「解析规则」「界面设计 · 导入页」

**Status:** resolved

- [x] 操作行完整：「编辑题干」「改题型」「拆分」「与下一题合并」（最后一题不可用）……「删除」
- [x] 点「编辑题干」或「改题型」→ 该行展开成预填的录入表单（题型、题干、选项 + 「正确」、答案、解析；匹配题是共用选项 + 子题），底部「完成 / 取消」；「完成」后回到紧凑行，序号不变
- [x] 题型互转只允许 单选 ↔ 多选 ↔ 判断：多选 → 单选而答案多于一个、转成或转出判断题时答案清空标红；匹配题不可互转（select 里不可选）
- [x] 拆分：在题干文本框里放光标，点「从此处拆分」，光标后的文字成为紧随其后的一题（无选项、缺答案标红），后续序号顺延
- [x] 合并：「与下一题合并」→ 题干相接，选项拼接并重排字母，答案跟着重排保留，解析相接；任一题是匹配题时不可合并
- [x] 所有编辑只改草稿，不经过应用核心；`commitReview` 仍在写入前校验，拆分出的缺答案题会拦住写入
- [x] seam 测试：经 `commitReview` 写入经过拆分、合并、改题型的草稿，题目列表与编辑结果一致；不合法的草稿被拒绝

# 07: 练习与判定

**What to build:** 在分组页点「开始练习」进入一轮：题目以随机顺序出现（本张先用注入的 random 打乱全部题目，到期优先在 08 加），用户作答单选 / 多选 / 判断题，点「提交」后立刻看到对错、正确答案和解析，再点「下一题」；一轮做完出现本轮完成块，可以开始重新打乱的下一轮。每次作答都被记录，题目列表和练习页显示历史对错次数。匹配题暂不进轮。

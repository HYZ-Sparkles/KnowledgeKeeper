# 20: 从备份恢复

**What to build:** 在备份页点「选择备份文件」，选一个备份 JSON，对话框写明文件里有多少分组、多少题、当前的会消失且不能撤销；确认后整库替换并回到首页。不是备份文件或版本不支持时给明确警示，题库保持不变。

**Blocked by:** 19 导出备份与「上次备份」状态

**Spec:** spec.md「用户故事 51」「备份」「界面设计 · 备份页 / 对话框」

**Status:** ready-for-agent

- [ ] 备份页面板「从备份恢复」+ 按钮「选择备份文件」→ 系统文件选择器
- [ ] 选文件后先读出文件里的分组数、题数，弹对话框「用「文件名」替换当前题库？文件里有 N 个分组、M 道题；当前的分组、题目和作答记录都会消失，不能撤销。」→ [取消] + 红色确认
- [ ] 确认后 `restore` 整库替换：旧的分组、题目、作答、排期全部消失；「上次备份」变为备份文件中的值；toast「已恢复 N 个分组、M 道题」，回首页，左栏同步
- [ ] 文件不是 KnowledgeKeeper 备份、JSON 损坏、schema 版本不支持 → 面板下方持久警示条，题库不变、不弹确认
- [ ] seam 测试：备份 → 改动 → 恢复后题库与备份时一致（分组、题目、排期、收藏、作答、元数据）；恢复后旧数据消失；上次备份时间取自文件；非法输入报错且数据不变

# 10: 分组统计

**What to build:** 首页和分组页能看到每组的掌握情况：题数、总体正确率（没有作答时显示「尚未练习」）、各题型数量、排期分布图（八个刻度：六个间隔 + 完成复习 + 未排期）；首页顶部有「N 道今天到期」「N 道在复习中」两个药丸。所有数字由作答和排期实时计算，不单独存储。

**Blocked by:** 08 遗忘曲线排期

**Spec:** spec.md「用户故事 49」「数据模型（统计实时计算）」「界面设计 · 首页 / 分组页」

**Status:** ready-for-agent

- [ ] 正确率 = 组内全部作答的 对 /（对 + 错），取整百分比；没有作答显示「尚未练习」且不画细条。首页分组行：「N 题」+「正确率 N%」细条（52px）
- [ ] 分组页副标「N 道题，总体正确率 N%，今天到期 N 道。…」；分组页药丸：单选题 / 多选题 / 判断题 / 匹配题各 N，为 0 的不显示
- [ ] 排期分布图：一根基线、八个刻度，高度 = 题数（最高 40px），复习中为橙、完成复习与未排期为褐，数量标在刻度上方，为 0 的刻度留 2px 灰线且不标数字
- [ ] 首页药丸：「N 道今天到期」（橙）、「N 道在复习中」（处于第 1–6 个间隔的题数）；「上次备份」药丸在 19 加
- [ ] seam 测试：分组列表返回的题数、正确率、到期数、在复习数、各题型数、八个刻度的题数与固定数据一致

# 19: 导出备份与「上次备份」状态

**What to build:** 在备份页点「导出备份文件」得到一个 JSON 文件（含分组、题目、排期、收藏、作答记录和题库元数据，带 schema 版本号），经浏览器下载到「文件」app；导出的同时更新「上次备份」时间，首页与备份页显示「上次备份 N 天前」，尚未备份或超过 7 天为橙色提醒。

**Blocked by:** 11 匹配题练习, 12 收藏与只看收藏

**Spec:** spec.md「用户故事 50、52、53」「备份」「界面设计 · 备份页」

**Status:** resolved

- [x] 顶栏加入「备份」；备份页：标题「备份与恢复」、副标、药丸「上次备份 …」「N 道题 · M 条作答」、面板「导出备份」+ 主按钮「导出备份文件」

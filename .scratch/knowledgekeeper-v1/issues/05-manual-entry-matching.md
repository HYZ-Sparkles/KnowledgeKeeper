# 05: 录入匹配题

**What to build:** 题型选「匹配题」时，表单出现「共用选项」和「子题」两块：共用选项是字母 + 文本的列表，每个子题有题干、单选 / 多选、在共用选项里点「正确」；两块都可增删。保存后分组页显示这道匹配题。

**Blocked by:** 03 录入单选 / 多选 / 判断题，分组页列出题目

**Spec:** spec.md「用户故事 20」「数据模型」「界面设计 · 录入页」

**Status:** resolved

- [x] 题型选「匹配题」→ 表单变成：题干、「共用选项」列表、「子题」列表、解析
- [x] 子题行：题干、单选 / 多选标签（可切换）、共用选项的「正确」按钮（单选子题只能点一个，多选子题可点多个）、删除子题
- [x] 校验：至少 2 个共用选项、至少 1 个子题、每个子题题干非空且有答案（多选子题至少 2 个）；不满足时「保存到题库」禁用并提示
- [x] 保存后留在表单、toast；分组页以「匹配题」标签列出这道题
- [x] seam 测试：录入的匹配题读回时共用选项、子题（题干、题型、答案）与录入一致；整道题是一个题目，排期与收藏都以整题为单位
- [x] 录入页右轨说明补一句匹配题的形态

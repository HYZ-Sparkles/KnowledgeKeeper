# 06: 题目页：编辑与删除

**What to build:** 在分组页点一道题进入题目页：顶部一行只读状态，主体是预填的录入表单，可改题干、选项、答案、解析，保存后回到列表且这道题的排期不变；「删除题目」经对话框确认后回到列表，作答记录和排期一起删除。

**Blocked by:** 04 分组管理与应用内对话框, 05 录入匹配题

**Spec:** spec.md「用户故事 21、22、23」「界面设计 · 题目页」

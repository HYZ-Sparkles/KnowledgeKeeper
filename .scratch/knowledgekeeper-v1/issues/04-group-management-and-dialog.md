# 04: 分组管理与应用内对话框

**What to build:** 用户可以新建分组（录入页的分组 select 里选「＋ 新建分组…」起名）、在分组页重命名分组、删除分组（对话框写明连带多少道题、不能撤销，确认后连同题目一起消失）。应用内对话框组件在这里建立，之后所有确认和命名都用它。

**Blocked by:** 03 录入单选 / 多选 / 判断题，分组页列出题目

**Spec:** spec.md「用户故事 4、24、25、26」「界面设计 · 对话框 / 分组页」

**Status:** ready-for-agent

- [ ] 对话框组件：标题 + 一句带数字的后果 + [取消] + [确认]，破坏性确认用红字；遮罩下内容不可点；不用原生 alert / confirm / prompt
- [ ] 录入页分组 select 末项「＋ 新建分组…」→ 命名对话框（文本框，空名字不可确认）→ 建好并选中
- [ ] 分组页工具栏右侧两个 ghost 文字按钮「重命名」「删除分组」（窄屏自然换行）；左栏分组列表随之增减与改名
- [ ] 删除对话框「删除「组名」及其 N 道题？不能撤销。」；确认后回首页，toast「已删除「组名」」
- [ ] 默认分组没有特殊保护，可重命名、可删除；分组 select 的默认选中规则：名为「错题集」的分组存在则选它，否则选第一个分组
- [ ] seam 测试：创建、重命名后分组列表同步；删除分组连带删除其中题目、作答记录与排期，其他分组不受影响

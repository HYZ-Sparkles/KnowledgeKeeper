# 参照站实测

来源：`https://csgraduates.com/constitution_principle/representation/`
方法：`curl` 取 CSS + 1440×900 截图逐像素取样（Pillow），`ref_card.py measure` 量面积占比。

## 面积与骨架（1440×900）

- 底色 `#FDFAF5`（暖纸）占 92% 画面，**彩色面积 0%**——颜色全部在字上，不在块上。
- 三栏：左栏 240px（16.7%）｜内容栏起于 x=285、宽约 930px｜右轨 220px。
- 两条 1px 发丝线分隔三栏，颜色 `#E4E0DD`。
- 顶部导航高 56px，底色与页面相同（不是深色条），底部一条发丝线。
- 从上到下十段内容占比：26 / 11 / 8 / 9 / 10 / 8 / 7 / 4 / 3 / 14 —— 第一段（导航＋标题区）吃掉了四分之一的高度，正文之后留了 14% 的空。

## 字

- 中文走系统字（`-apple-system` / PingFang SC 一带），没有装中文 webfont。
- h1 40px 粗，副标 15px，面包屑 14px，侧栏 14px，导航 15px。**标题:正文 ≈ 2.7 : 1**，靠字重和留白拉层级，不靠字号爆炸。
- 橙色条目行高约 64px，一行一个，前面一个「·」。

## 组件动作

- 面包屑：`组成原理 / 数据表示和计算`，全琥珀色，斜杠前后各一个空格。
- pill：小圆角、浅色底、12–13px，跟在副标下面一行。
- 右轨：图标 + 短句（`章节视图` / `隐藏工具栏`），橙色。
- 侧栏：`▸` 三角可折叠，当前项加粗，父项比子项深。
- 内容区没有卡片、没有阴影、没有圆角块，全靠发丝线和留白分区。

## 不借

Docsy 的组件本身（搜索框、明暗主题切换、右下角 FAB 工具盘）、它的插画风、它的图标库。

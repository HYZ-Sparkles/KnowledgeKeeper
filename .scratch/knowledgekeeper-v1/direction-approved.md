## 改动记录

- 顶部导航是唯一入口：`题库 / 导入 / 录入 / 备份`（原来三处、三种文案，现在一处、一套文案）。
- 左栏只剩分组树——和参照站一样，侧栏就是目录，不放动作。
- 右轨按视图给「本轮 / 这道题 / 校对 / 存储」这类只和当前视图有关的信息，不再复述全局入口。
- 顺带按同一条原则清掉了另外三处重复：
  - 右轨「存储」里的「上次备份：3 天前」从可点入口改成纯文字（状态归状态，入口归入口）。
  - 分组页右轨「本轮」里的「开始练习 / 只看到期的 3 道 / 只看收藏的 2 道」删掉——
    内容栏那颗蓝色主按钮和「只看收藏」开关已经能做同样的事。
  - 导入校对页右轨的「写入 12 道题」删掉；写入按钮收进顶部那条警示栏里，一屏只有一个。
    补上缺的答案后警示栏变绿、按钮解禁（截图 `shots/dir-1/review-filled.png`）。
- 录入页表单压缩了行距，让「保存到题库」在 1440×900 首屏内可见（原来掉在折叠线以下）。

分工定下来：**顶栏是动作，左栏是目录，右栏是当前视图的信息，内容栏一件事一个主动作。**

## 收藏：只在做题时，题目行右边一个都不留（用户第四、五次反馈）

- 第四次原话：「没事改回去吧，我才发现收藏在右边」——意思是练习页已经有收藏了，
  列表那侧不必保留。（我当时理解反了，把列表的星加了回去。）
- 第五次原话：「不是，收藏按原来的来，但整体单选题、多选题右边的收藏给我去掉。」
- 落定：
  - **收藏只有一个入口**：练习页题目行右侧那颗「收藏 / 已收藏」按钮（40px，带文字）。
  - **列表里彻底没有星**：题目行右边不再有任何收藏控件或标记（原来那个只读 ★ 也去掉了）。
    想知道哪些题收藏过，用「只看收藏」过滤和左栏「收藏 N」。
  - 和 spec 的差异：spec 的 user story 27 写的是「在题目列表和练习页点星收藏」。
    按用户意见，列表侧整个去掉了。

## 数字改为从数据算出来（自查，非用户提出）

改收藏时发现的：点左栏另一个分组，标题换了，但下面的题数、正确率、到期数、题型药丸、
排期刻度尺全是写死的计算机组成原理那套。根因是页面上每个数字都是硬编码。

- 数据收成一个 `LIB`：四个分组，25 道题，每题只有 `题型 / 题干 / 间隔阶段 / 到期日 / 对错次数 / 收藏`。
- 页面上所有数字由它算：题数、正确率、到期数、在复习中、题型分布、排期刻度、左栏计数、
  备份页的「N 道题 · M 条作答」、右轨的本轮说明和删除确认。
- 练习按当前分组开始：面包屑、`第 n / N`、到期未做数、右轨的「第几格」都跟着分组走。
- 四个分组各自至少有一道可作答的题（原来是计组独占练习页）。

## 收藏的位置（用户第三次反馈）

- 用户原话：「还有，你这个收藏的 UI 做得不合理！它应该是在做题的时候收藏，不是在一开始收藏。」
- 原来：题目列表每行右侧一个可点的星（空星也画出来），练习页右轨藏着一个「加入收藏」而且没接逻辑
  —— 等于只有「一开始」那个能点，做题时反而收藏不了。
- 现在：**收藏只在做题时发生**。练习页题目行右侧一个 40px 的星按钮（`收藏 / 已收藏`），
  点了立刻生效，左栏「收藏 N」和「只看收藏」跟着变。列表里不再放可点的星，
  只在已收藏的题后面留一个 11px 的橙色 ★ 作为结果标记。
- 收窄之后又改回来了（见下）。

## 产品名订正（用户第二次反馈）

- 用户原话：「左上角的名字就叫 Knowledge Keeper，不要叫错的吧。」
- 原来左上角写的是「错题本」——把**默认分组名**（错题集）和**产品名**混了。
  按 `GLOSSARY.md`：错题是题目的状态，错题集是系统自带的默认分组，产品叫 KnowledgeKeeper。
- 三版都改了：品牌名 `Knowledge Keeper`（拉丁字收紧字距、17px），`<title>` 跟着改，
  导出的备份文件名改成 `KnowledgeKeeper-2026-10-14.json`。
  分组名「错题集」不动——它本来就是默认分组。

## 现在的状态

六个视图都可点：题库 / 分组 / 练习（单选·多选·判断 + 匹配题）/ 导入（粘贴 → 校对 → 写入）/
录入 / 备份。可点的真交互：

- 分组树切分组、只看收藏过滤、星标收藏切换
- 练习三题型作答与判定，右轨排期信息跟着换
- 匹配题四个子题逐题锁定判定
- 校对页补上缺的答案 → 警示栏转绿 → 写入按钮解禁 → 写入后回到分组

## 尚未做（下一步）

- 仍是原型态：录入表单不落库、导入不真解析、备份不真写文件。
- 应用核心 seam（spec 的 interface）未接。接的时候这六个视图对应：
  分组列表 / 题目列表 / 练习 / 导入校对 / 录入 / 备份恢复，各自只调一个 module 方法。

# 本地桌面应用，不做 Web 服务

KnowledgeKeeper 最初被设想为 PWA，我们改为 Tauri 2 构建的本地桌面应用：每个用户运行自己的实例，没有账号、没有后端、没有跨设备同步，本机的 SQLite 文件是唯一的数据源。原因是：浏览器存储会被清理导致丢题；不想部署和维护服务器；用户的题目文件不出本机。被否决的方案：PWA（受浏览器存储淘汰和国内网络托管影响）、客户端-服务器 SaaS（账号、托管、维护成本）。

## Consequences

- 换电脑和备份完全依赖应用内的备份 / 恢复功能，没有云端兜底。
- 安装包不做代码签名；Windows SmartScreen 的"未知发布者"警告由分发者向用户说明，应用内不处理。

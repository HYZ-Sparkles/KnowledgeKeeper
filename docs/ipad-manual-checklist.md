# iPad 手测清单（ticket 22）

每一项都要由人在**真实 iPad 的 Safari** 上执行并当场记录：勾选结果，填好日期、设备 / iPadOS 版本与备注。
按 spec「Testing Decisions」，React 渲染、service worker、manifest、iPad 文件选择与下载**故意不做 seam 自动化测试**，只能用这份清单人工覆盖。

约定：**不通过的项写成对应 ticket 的备注，不在本张里修**；归属见文末映射表。

前置：部署地址可访问；题库里有一个含题与错题的分组；手上有一份可恢复的备份文件。从 Safari 打开首页开始。

1. 在仓库打开 `docs/ipad-manual-checklist.md`。
2. 确认以下每项都有「通过 / 不过」「日期」「设备 / iPadOS 版本」「备注」。

- [ ] 通过　[ ] 不过　日期：____　设备 / iPadOS 版本：____　备注：____

## 2. 安装：Safari 分享 → 添加到主屏幕 → 全屏

1. Safari 打开部署地址，点「分享 → 添加到主屏幕」并完成添加。
2. 回主屏点新图标打开：应为全屏、无地址栏；首页横幅
   `在 Safari 点「分享 → 添加到主屏幕」，全屏使用，存储也不会被 Safari 清理。[知道了]` 不再出现。
3. 若横幅仍在，记下是否点过 `[知道了]`（按设备记，不进备份）。

## 3. 离线：飞行模式下六个视图与题目页

1. 在线时打开一次应用后开飞行模式，从主屏图标打开。
2. 依次进入首页 `#home`、分组页 `#group`、练习页 `#practice`、导入页 `#import`、录入页 `#entry`、备份页 `#backup`；再从分组页点题目行进入题目页 `#question`。
3. 在练习页作答一题并切换「收藏 / 已收藏」；在录入页保存一道题，应出现 `已保存到「组名」`。

- [ ] 通过　[ ] 不过　日期：____　设备 / iPadOS 版本：____　备注：____

## 4. 文件选择与备份往返

1. 导入页点 `从「文件」选择`，分别选 .pdf、.docx、.xlsx 各一次：按钮变 `正在提取…`，完成后文本框上方显示 `已从「文件名」提取约 N 字`，可点 `开始校对`。
2. 再选一个 .doc：持久警示条应给出 `.doc 提示`：`请在 Word 里另存为 .docx`，不生成草稿。
3. 备份页点 `导出备份文件`：下载 `KnowledgeKeeper-YYYY-MM-DD.json` 到「文件」app，出现 `已导出`、「上次备份」更新。
4. 点 `选择备份文件`，从「文件」选刚导出的 JSON：对话框写明 `用「文件名」替换当前题库？…`，确认后出现 `已恢复 N 个分组、M 道题` 并回首页。

## 5. 横竖屏：右轨与对话框

1. 竖屏进练习页（≤960 档）：右轨消失；标签行仍有题型、`第 3 个间隔 · 10 月 12 日到期 · 5 对 2 错` 与 `收藏 / 已收藏`。
2. 转横屏：右轨恢复六格刻度与 `这次答对进第 4 个间隔（7 天），答错回到第 1 个间隔`。
3. 在分组页点「重命名」弹出对话框：输入法可弹出并输入；「取消」「确认」均可见可点，不被键盘遮挡。

## 6. 长列表校对页：sticky 警示条与题号跳转

1. 粘贴一份答案故意缺两题的长文本，点 `开始校对`。
2. 顶部 sticky 警示条显示 `识别到 N 道题，答案 M 个。第 7、9 题缺答案，标红了。`；点题号 `7` 应滚到对应行。
3. 补齐答案后转绿 `识别到 N 道题，答案 N 个，都齐了。`，`写入 N 道题` 解禁；写入后 toast `已写入 N 道题到「组名」`。

## 7. 匹配题长子题列表：共用选项跟着滚动

1. 按 `docs/matching-sticky-test-data.md` 把测试题（20 / 8 / 2 个子题的匹配题 + 1 道普通题）导入新建的「滚动验证」分组，进练习页；一轮内顺序随机，按题干开头的【…】认题。
2. 竖屏慢慢往下翻：「共用选项」面板应一直停在顶栏下方，字母和文本都看得见；到最后一个子题之后才随题目一起滚走，不挡住「提交」。
3. 横屏重复一次。共用选项多到超过一屏时（【长选项 10】），面板内部可滚，标题「共用选项」不跟着滚走，翻面板不会带动整页。
4. 验完删掉「滚动验证」分组，别让测试题混进正式题库。

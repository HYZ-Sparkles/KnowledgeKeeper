# 匹配题共用选项 sticky：手测数据

用于人工验证工单 24「子题多时共用选项被滚走」。题目内容是计算机网络的概念匹配，只为把页面撑长，答案对错不重要。

## 怎么装进去

1. 导入页 → 把下面「粘贴文本」整段粘进文本框 → `开始校对`。
2. 校对页应显示「识别到 4 道题，答案 4 个，都齐了。」，没有红色缺答案。
3. `放进哪个分组` 选 `＋ 新建分组…` 建一个「滚动验证」分组 → `写入 4 道题`。
4. 分组页点 `▶ 开始练习`。一轮里这 4 道题顺序随机，按题干开头的【…】认题。

## 人工验证清单

每题都在**真实 iPad Safari** 上做，先横屏再竖屏；竖屏可用 Split View 把窗口压到 ≤760 档再看一次单列布局。
`docs/ipad-manual-checklist.md` 第 7 项是这部分的正式记录位。

**【长子题 20】主场景**

- [ ] 向下滚 2–3 屏：左侧「共用选项」面板一直停在顶栏下方约 12px 处，A–J 字母与文字都看得见；题干、标签行滚走不影响面板。
- [ ] 滚到第 18–20 个子题：面板仍在原位，能照着它点选最后几个子题的 chip；20 个子题全部选完才能提交。
- [ ] 继续滚到「提交」按钮与提交后的反馈块：面板随整道匹配题一起离开，不悬在按钮上方、不遮住「答对 / 答错」与「下一题」。
- [ ] 提交后往回滚，逐个看第 1、10、20 个子题的绿框 / 红框 chip，面板仍跟着走。
- [ ] 点「下一题」：回到页面顶部，下一题的面板从正常位置开始，不残留上一题的面板或滚动偏移。

**【长选项 10】面板内滚动**

- [ ] 面板高度不超过一屏，右侧出现可滚的滚动条；能滚到 J。
- [ ] 在面板内部滚动时，标题「共用选项」不跟着滚走，整页也不跟着滚（`overscroll-behavior: contain`）。
- [ ] 页面继续往下翻子题时，面板仍固定在顶栏下方。

**【短对照 2】短页面**

- [ ] 页面不足一屏时面板不跳动、不盖住「提交」，chip 可正常点选并能提交。

**【普通题】与窄屏**

- [ ] 切到普通题时没有共用选项面板，说明 sticky 不会带出匹配题。
- [ ] ≤760 单列：面板贴在顶栏下方、高度不超过约半屏，子题在下方滚动，不遮挡提交行。

## 收尾

验证完把「滚动验证」分组整个删掉，别让测试题混进正式题库和备份。
